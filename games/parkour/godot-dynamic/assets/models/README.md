# Authored 3D models

`bazaar_district.glb` is generated by `godot/tools/generate_city_assets.py`.
It contains modeled façades, arches, balconies, shutters, roof details,
market stalls, canopies, bridges and sparse traversal ropes.

The generated GLB embeds the project sandstone texture and is the first
high-detail replacement for the old raylib primitive renderer.

The editable Blender source is kept in
`godot/source_art/bazaar/bazaar_district.blend`, outside Godot's runtime
import scan.
