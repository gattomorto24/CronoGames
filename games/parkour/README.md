# Crono Parkour

- `client/` contiene l'export WebGL servito da CronoGames.
- `godot-dynamic/` è il sorgente completo e attuale, con città mediterranea,
  porting touch e bootstrap WebGL.
- `godot/` è il prototipo storico mantenuto per riferimento: non è la sorgente
  usata dall'export pubblicato.

Per lavorare sul gioco apri `godot-dynamic/project.godot`; le istruzioni per
importare le risorse e rigenerare il client sono nel suo README.
